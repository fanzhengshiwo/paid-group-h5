# 付费进群 H5 实现说明

这个目录是一个可直接打开的静态 H5 原型，当前是“页面展示微信赞赏码 + 人工核验拉群”版本，已包含套餐选择、表单校验、收款码展示、付款后提交入群信息。

## 最快上线链路

1. 页面展示真实微信赞赏码。
2. 用户选择套餐，填写手机号和微信号。
3. 用户扫码付款，付款备注填写手机号后四位或订单号。
4. 用户点击“我已付款，提交入群信息”。
5. 你按订单号、金额、付款备注人工核验后拉群。

## 自动化升级链路

1. H5 调用后端 `POST /api/orders` 创建订单。
2. H5 用微信 JSAPI、微信 H5 支付或支付宝 WAP 支付拉起收银台。
3. 支付平台异步通知后端，后端验签并把订单改为 `paid`。
4. H5 轮询 `GET /api/orders/:id` 查询订单状态。
5. 后端只在订单已支付时返回短期有效的入群二维码、群口令或客服引导。

## 后端表结构建议

```sql
orders(id, order_no, user_phone, user_wechat, plan, amount, status, paid_at, created_at)
group_invites(id, order_id, invite_token, qr_url, expires_at, used_at)
payment_events(id, order_no, provider, event_type, raw_payload, verified, created_at)
```

## 关键注意点

- 不要在前端判断“是否付款成功”，以前端展示为准会被绕过。
- 支付回调必须验签，金额和订单号必须二次校验。
- 入群二维码不要做永久公开链接，建议短期有效、可撤销、可追踪。
- 如果是微信群，常见做法是支付后展示客服微信或企业微信活码，由管理员自动/半自动拉群。
- 国内支付接入通常需要营业执照、商户号、域名备案和支付目录配置。
